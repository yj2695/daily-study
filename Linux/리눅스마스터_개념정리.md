# 리눅스 마스터 2급 개념정리

## 1. 리눅스 개요

### 1.1 리눅스의 특징

- 유닉스(UNIX) 계열의 오픈소스 운영체제, 리누스 토르발스가 1991년 최초 개발
- **커널(Kernel)**: 하드웨어와 소프트웨어를 중개하는 운영체제의 핵심
- **GPL(GNU General Public License)** 라이선스 적용 → 소스코드 공개, 자유로운 배포/수정 가능
- 멀티유저(Multi-user), 멀티태스킹(Multi-tasking) 지원
- 이식성(Portability)이 뛰어나 다양한 하드웨어 아키텍처 지원

### 1.2 주요 배포판

| 계열           | 대표 배포판                       | 패키지 관리     |
| -------------- | --------------------------------- | --------------- |
| Red Hat 계열   | RHEL, CentOS, Fedora, Rocky Linux | RPM / YUM / DNF |
| Debian 계열    | Debian, Ubuntu, Mint              | DEB / APT       |
| Slackware 계열 | Slackware, SUSE                   | RPM(SUSE)       |

### 1.3 리눅스 부팅 과정

```
BIOS/UEFI → Boot Loader(GRUB) → Kernel 로딩 → init/systemd 실행 → 런레벨(타겟) 서비스 시작 → 로그인
```

- **GRUB**: 부트로더, `/boot/grub2/grub.cfg`에서 설정
- **systemd**: 최근 배포판의 초기화 프로세스(init 대체), `systemctl` 명령으로 제어

### 1.4 런레벨 / systemd 타겟

| 런레벨 | systemd 타겟      | 의미                     |
| ------ | ----------------- | ------------------------ |
| 0      | poweroff.target   | 시스템 종료              |
| 1      | rescue.target     | 단일 사용자 모드         |
| 3      | multi-user.target | 텍스트 모드(다중 사용자) |
| 5      | graphical.target  | 그래픽 모드              |
| 6      | reboot.target     | 재부팅                   |

```bash
systemctl get-default        # 현재 기본 타겟 확인
systemctl set-default multi-user.target   # 기본 타겟 변경
systemctl isolate graphical.target        # 즉시 타겟 전환
init 3                       # 구식 런레벨 전환 명령
```

### 1.5 오픈소스 라이선스

| 라이선스                             | 특징                                                                                              |
| ------------------------------------ | ------------------------------------------------------------------------------------------------- |
| **GPL** (GNU General Public License) | 리눅스 커널 라이선스. 수정/재배포 시 **소스코드 공개 의무**(카피레프트), 파생 프로그램도 GPL 적용 |
| **LGPL** (Lesser GPL)                | 라이브러리용, 링크만 해도 되며 소스 공개 의무 완화                                                |
| **BSD 라이선스**                     | 소스 공개 의무 없음, 상업적 이용·비공개 파생 허용(카피레프트 아님)                                |
| **MIT 라이선스**                     | BSD와 유사하게 매우 자유로운 라이선스, 저작권 표시만 유지하면 재배포/수정/상업적 이용 자유        |
| **모질라 라이선스(MPL)**             | 파일 단위로 공개 의무 적용(GPL보다 완화된 카피레프트)                                             |

- **카피레프트(Copyleft)**: 저작권(Copyright)의 반대 개념으로, 소스코드를 공개하고 누구나 자유롭게 사용·수정·재배포할 수 있게 하는 것 (단, 파생물도 동일 라이선스를 따라야 함 = GPL의 핵심 원칙)
- **오픈소스 소프트웨어(OSS)의 자유 4가지**: 실행의 자유, 연구/수정의 자유(소스코드 접근), 재배포의 자유, 개선판 배포의 자유

### 1.6 리눅스 역사 & GNU 프로젝트

- **1983년**: 리처드 스톨만(Richard Stallman)이 **GNU 프로젝트** 시작 → 유닉스 호환 자유소프트웨어 운영체제를 목표로 함(GNU = "GNU's Not Unix")
- **1991년**: 리누스 토르발스(Linus Torvalds)가 리눅스 **커널**을 최초 공개(핀란드 헬싱키 대학 재학 중)
- 엄밀히 "리눅스"는 커널만을 의미하며, GNU 도구 + 리눅스 커널이 합쳐진 것을 **GNU/Linux**라고도 부름
- **POSIX(Portable Operating System Interface)**: 유닉스 계열 OS 간 호환성을 위한 표준 인터페이스 규격, 리눅스는 POSIX 호환

### 1.7 설치 방식 개요

- 설치 전 확인 사항: 파티션 구성(`/`, `/boot`, `/home`, `swap` 등 분리 여부), 부트로더(GRUB) 설치 위치, 네트워크/타임존/키보드 설정
- **스왑(Swap) 파티션**: 물리 메모리 부족 시 사용하는 가상 메모리 공간, 통상 물리 메모리의 1~2배 권장(메모리 용량에 따라 상이)
- 설치 방식: CD/DVD/USB를 이용한 로컬 설치, PXE를 이용한 네트워크 설치, 킥스타트(Kickstart)를 이용한 무인 자동 설치(RHEL 계열)
- 파티션 방식: MBR(최대 4개의 주 파티션, 2TB 제한) vs **GPT**(GUID Partition Table, 대용량 디스크 지원, UEFI 부팅과 함께 사용)

### 1.8 커널 구성 요소

- 프로세스 관리, 메모리 관리, 파일시스템 관리, 장치 드라이버, 네트워크 관리로 구성
- 커널 버전 확인: `uname -r`
- 커널 버전 표기 규칙(예: 5.14.0): 주 버전.부 버전.패치 버전 — 과거에는 부 버전이 짝수면 정식(stable), 홀수면 개발(unstable) 버전이었으나 최근 커널(3.x 이후)은 이 규칙을 사용하지 않음

### 2.1 디렉토리 구조 (FHS: Filesystem Hierarchy Standard)

| 디렉토리         | 설명                                |
| ---------------- | ----------------------------------- |
| `/`              | 최상위 루트 디렉토리                |
| `/bin`, `/sbin`  | 기본/시스템 실행 명령어             |
| `/etc`           | 시스템 설정 파일                    |
| `/home`          | 사용자 홈 디렉토리                  |
| `/var`           | 로그, 메일, 캐시 등 가변 데이터     |
| `/usr`           | 응용 프로그램, 라이브러리           |
| `/proc`          | 프로세스/커널 정보(가상 파일시스템) |
| `/dev`           | 장치 파일                           |
| `/tmp`           | 임시 파일                           |
| `/lib`, `/lib64` | 커널 모듈, 공유 라이브러리          |
| `/boot`          | 부팅 관련 커널, GRUB 파일           |
| `/mnt`, `/media` | 마운트 포인트                       |
| `/root`          | 관리자(root) 홈 디렉토리            |

### 2.2 파일 종류

- 일반 파일(`-`), 디렉토리(`d`), 링크(`l`), 문자 장치(`c`), 블록 장치(`b`), 소켓(`s`), 파이프(`p`)

### 2.3 아이노드(Inode)

- 파일의 메타데이터(소유자, 권한, 크기, 타임스탬프, 데이터 블록 위치)를 저장
- 파일명은 디렉토리 엔트리에 별도 저장되어 아이노드 번호와 매핑
- `ls -i` 로 아이노드 번호 확인

### 2.4 링크

- **하드 링크(Hard Link)**: 동일 아이노드를 공유, 원본 삭제해도 유지, 디렉토리/타 파일시스템 불가
  ```bash
  ln 원본파일 링크파일
  ```
- **심볼릭 링크(Symbolic Link)**: 경로를 저장하는 별도 파일(단축 아이콘 개념), 원본 삭제 시 깨짐
  ```bash
  ln -s 원본파일 링크파일
  ```

### 2.5 주요 파일시스템 종류

- **ext2/ext3/ext4**: 리눅스 표준 파일시스템(ext3부터 저널링 지원)
- **XFS**: 대용량/고성능 저널링 파일시스템(RHEL 기본)
- **Btrfs**: 스냅샷, 볼륨관리 지원 차세대 파일시스템
- **NFS**: 네트워크 파일 공유
- **swap**: 가상 메모리(스왑) 영역

### 2.6 마운트

```bash
mount /dev/sdb1 /mnt/data      # 마운트
umount /mnt/data               # 마운트 해제
mount -a                       # /etc/fstab 전체 마운트
df -h                          # 마운트된 파일시스템 사용량 확인
```

- `/etc/fstab`: 부팅 시 자동 마운트 설정 파일
  ```
  <device>  <mount point>  <fs type>  <options>  <dump>  <pass>
  ```

## 3. 사용자 및 그룹 관리

### 3.1 관련 파일

| 파일              | 설명                                                             |
| ----------------- | ---------------------------------------------------------------- |
| `/etc/passwd`     | 사용자 계정 정보 (계정명:패스워드(x):UID:GID:설명:홈디렉토리:쉘) |
| `/etc/shadow`     | 암호화된 패스워드, 만료 정책 저장                                |
| `/etc/group`      | 그룹 정보 (그룹명:패스워드:GID:그룹원)                           |
| `/etc/gshadow`    | 그룹 패스워드 보안 정보                                          |
| `/etc/login.defs` | 계정 생성 시 기본 정책(UID 범위, 패스워드 정책)                  |
| `/etc/skel`       | 신규 계정 생성 시 복사되는 기본 홈 디렉토리 템플릿               |

### 3.2 사용자 관리 명령어

```bash
useradd -m -s /bin/bash -g users -G wheel user1   # 사용자 추가(-m 홈 생성, -g 기본그룹, -G 보조그룹)
passwd user1                                       # 패스워드 설정
usermod -aG wheel user1                            # 그룹 추가(append)
userdel -r user1                                   # 사용자 및 홈 삭제
id user1                                           # UID/GID 확인
who / w                                            # 로그인 사용자 확인
```

### 3.3 그룹 관리 명령어

```bash
groupadd developers
groupmod -n newname oldname
groupdel developers
gpasswd -a user1 developers   # 그룹에 사용자 추가
```

### 3.4 UID 범위

- 0: root
- 1~999(또는 배포판별 상이): 시스템 계정
- 1000 이상: 일반 사용자 계정

## 4. 파일 권한 관리

### 4.1 권한 표기

```
- rwx rwx rwx
파일종류 소유자 그룹 기타사용자
```

- r(read)=4, w(write)=2, x(execute)=1

### 4.2 권한 변경 명령어

```bash
chmod 755 file.sh        # 숫자 모드
chmod u+x,g-w file.sh    # 기호 모드
chown user1:group1 file  # 소유자/그룹 변경
chgrp group1 file        # 그룹만 변경
```

### 4.3 특수 권한

| 권한       | 심볼              | 숫자 | 설명                                                           |
| ---------- | ----------------- | ---- | -------------------------------------------------------------- |
| SetUID     | `s`(소유자 x자리) | 4000 | 실행 시 파일 소유자 권한으로 실행 (예: passwd)                 |
| SetGID     | `s`(그룹 x자리)   | 2000 | 실행 시 그룹 권한 상속, 디렉토리에 적용 시 하위 파일 그룹 상속 |
| Sticky Bit | `t`(기타 x자리)   | 1000 | 디렉토리 내 파일은 소유자만 삭제 가능 (예: /tmp)               |

```bash
chmod 4755 file   # SetUID 부여
chmod 1777 /tmp   # Sticky bit
```

### 4.4 기본 권한(umask)

- 파일 기본 666, 디렉토리 기본 777에서 umask 값을 뺀 값이 실제 생성 권한

```bash
umask        # 현재 값 확인 (기본 022)
umask 027    # 변경
```

## 5. 프로세스 관리

### 5.1 프로세스 확인

```bash
ps aux            # 전체 프로세스 확인 (BSD 스타일)
ps -ef             # 전체 프로세스 확인 (UNIX 스타일)
top / htop         # 실시간 프로세스 모니터링
pstree             # 프로세스 트리 구조
```

### 5.2 프로세스 상태

- R(Running), S(Sleep), D(Uninterruptible sleep), T(Stopped), Z(Zombie)

### 5.3 프로세스 제어

```bash
kill -9 PID          # 강제 종료(SIGKILL)
kill -15 PID         # 정상 종료 요청(SIGTERM)
killall 프로세스명
pkill 프로세스명
nice -n 10 command   # 우선순위 지정하여 실행(-20~19, 낮을수록 높은 우선순위)
renice 5 -p PID      # 실행중 우선순위 변경
```

### 5.4 포그라운드/백그라운드

```bash
command &         # 백그라운드 실행
jobs               # 작업 목록 확인
fg %1 / bg %1      # 포그라운드/백그라운드 전환
nohup command &    # 로그아웃 후에도 계속 실행
Ctrl+Z             # 작업 일시정지(suspend)
```

### 5.5 예약 작업

```bash
crontab -e         # 사용자 crontab 편집
crontab -l         # 목록 확인
# 분 시 일 월 요일 명령
0 2 * * * /backup.sh    # 매일 새벽 2시 실행

at 10:00           # 1회성 예약 작업
atq                # 예약 목록
```

## 6. 패키지 관리

### 6.1 RPM 계열 (RHEL, CentOS, Fedora)

```bash
rpm -ivh package.rpm     # 설치 (i:install, v:verbose, h:hash)
rpm -Uvh package.rpm     # 업그레이드
rpm -e package           # 삭제
rpm -qa                  # 설치된 패키지 목록
rpm -qi package          # 패키지 정보
rpm -ql package          # 패키지가 설치한 파일 목록
```

### 6.2 YUM / DNF (RPM 의존성 자동 해결)

```bash
yum install httpd
yum remove httpd
yum update
yum list installed
dnf install httpd     # DNF는 YUM의 차세대 버전(Fedora, RHEL8+)
```

### 6.3 DEB 계열 (Debian, Ubuntu)

```bash
dpkg -i package.deb
dpkg -r package
apt-get install httpd
apt-get remove httpd
apt-get update && apt-get upgrade
apt-cache search httpd
```

### 6.4 소스 컴파일 설치

```bash
tar xvzf source.tar.gz
cd source
./configure
make
make install
```

## 7. 쉘(Shell)과 쉘 스크립트

### 7.1 주요 쉘 종류

- **sh(Bourne Shell)**, **bash(Bourne Again Shell, 기본 쉘)**, **csh/tcsh**, **ksh**, **zsh**
- 로그인 쉘 확인/변경: `/etc/passwd`의 마지막 필드, `chsh -s /bin/bash`

### 7.2 환경변수

```bash
echo $PATH
export MY_VAR=value      # 환경변수 설정
env / printenv            # 전체 환경변수 확인
```

- 주요 설정 파일: `/etc/profile`(전체 사용자), `~/.bashrc`, `~/.bash_profile`(개별 사용자)

### 7.3 입출력 리다이렉션 & 파이프

```bash
command > file      # 표준출력 저장(덮어쓰기)
command >> file     # 표준출력 추가
command < file      # 표준입력
command 2> error.log  # 표준에러
command 2>&1        # 에러를 표준출력으로 병합
cmd1 | cmd2          # 파이프(cmd1 출력을 cmd2 입력으로)
```

### 7.4 쉘 스크립트 기본 문법

```bash
#!/bin/bash
# 변수 선언
NAME="linux"

# 조건문
if [ "$NAME" = "linux" ]; then
  echo "매치됨"
elif [ -f /etc/passwd ]; then
  echo "파일 존재"
else
  echo "불일치"
fi

# 반복문
for i in 1 2 3; do
  echo $i
done

while [ $i -lt 10 ]; do
  i=$((i+1))
done

# 함수
function myfunc() {
  echo "hello $1"
}
myfunc world
```

- 스크립트 실행: `chmod +x script.sh; ./script.sh` 또는 `bash script.sh`

### 7.5 자주 쓰는 텍스트 처리 명령어

```bash
grep -i "pattern" file      # 문자열 검색(대소문자 무시)
grep -r "pattern" dir/       # 재귀 검색
sed 's/old/new/g' file       # 문자열 치환
awk '{print $1}' file        # 필드 단위 처리
find / -name "*.log"         # 파일 찾기
find / -type f -mtime -1     # 1일 이내 수정된 파일
```

## 8.5 네트워크 기초 개념

### 8.5.1 OSI 7계층

| 계층 | 이름                  | 역할                            | 대표 장비/프로토콜     |
| ---- | --------------------- | ------------------------------- | ---------------------- |
| 7    | 응용(Application)     | 사용자 서비스 제공              | HTTP, FTP, SMTP, DNS   |
| 6    | 표현(Presentation)    | 데이터 표현/암호화/압축         | SSL/TLS, JPEG          |
| 5    | 세션(Session)         | 통신 세션 관리                  | NetBIOS                |
| 4    | 전송(Transport)       | 신뢰성 있는 전송, 포트 구분     | TCP, UDP               |
| 3    | 네트워크(Network)     | 경로 설정(라우팅), 논리주소(IP) | IP, ICMP, 라우터       |
| 2    | 데이터링크(Data Link) | 물리주소(MAC), 오류검출         | 이더넷, 스위치, 브리지 |
| 1    | 물리(Physical)        | 전기적 신호 전송                | 케이블, 허브, 리피터   |

- TCP/IP 4계층(실무 표준): 응용 계층 → 전송 계층 → 인터넷 계층 → 네트워크 액세스 계층
- 시험에서는 장비/프로토콜이 OSI 몇 계층인지 자주 출제

### 8.5.2 TCP vs UDP

| 구분        | TCP                           | UDP                        |
| ----------- | ----------------------------- | -------------------------- |
| 연결 방식   | 연결지향(Connection-oriented) | 비연결지향(Connectionless) |
| 신뢰성      | 높음(재전송, 순서보장)        | 낮음(전송 후 확인 안 함)   |
| 속도        | 상대적으로 느림               | 빠름                       |
| 대표 서비스 | HTTP, FTP, SSH, SMTP          | DNS(질의), DHCP, 스트리밍  |

**3-way Handshake**

1. SYN
2. SYN+ACK
3. ACK

연결 종료: **4-way Handshake(FIN/ACK)**

### 8.5.3 IP 주소 체계

- IPv4: 32비트
- IPv6: 128비트

| 클래스 | 첫 옥텟 | 기본 서브넷마스크   | 용도       |
| ------ | ------- | ------------------- | ---------- |
| A      | 1~126   | 255.0.0.0 (/8)      | 대규모     |
| B      | 128~191 | 255.255.0.0 (/16)   | 중규모     |
| C      | 192~223 | 255.255.255.0 (/24) | 소규모     |
| D      | 224~239 | -                   | 멀티캐스트 |
| E      | 240~255 | -                   | 실험/예약  |

사설 IP

- 10.0.0.0~10.255.255.255
- 172.16.0.0~172.31.255.255
- 192.168.0.0~192.168.255.255

- Loopback: 127.0.0.1 (localhost)

### 8.5.4 서브넷마스크 / CIDR

| CIDR | 서브넷마스크    | 가용 호스트 |
| ---- | --------------- | ----------: |
| /24  | 255.255.255.0   |         254 |
| /25  | 255.255.255.128 |         126 |
| /26  | 255.255.255.192 |          62 |
| /27  | 255.255.255.224 |          30 |
| /30  | 255.255.255.252 |           2 |

가용 호스트 = 2^(호스트 비트 수) - 2

### 8.5.5 게이트웨이 / DNS

- 기본 게이트웨이: 다른 네트워크로 나가는 라우터
- DNS: 도메인 ↔ IP 변환
- 조회 순서(리눅스): `/etc/hosts` → DNS(`/etc/resolv.conf`)
- `nsswitch.conf` 설정에 따라 순서 변경 가능

### 8.5.6 방화벽 / 포트

- 포트: 0~65535
- Well-known: 0~1023
- 등록 포트: 1024~49151
- 동적/사설 포트: 49152~65535
